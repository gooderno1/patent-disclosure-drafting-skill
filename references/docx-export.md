# DOCX 同步与公式核验

## 1. 基本原则

- `md` 是主稿，`docx` 是同步产物。
- 每次 `md` 发生结构性变化后，都要重新同步 `docx`。
- 行间公式和行内公式都必须进入 Word 数学对象，不能退化为普通文本。

## 2. 推荐流程

1. 先完成 `md` 修改
2. 再生成或更新 `docx`
3. 渲染页面图片做视觉核验
4. 修复问题后重新渲染

请直接调用 `documents` skill 处理 `docx`，不要在专利工作目录中重新搭建 Python 生成链路。

## 3. 重点核验页面

优先检查这些页面：

- `2.3` 大表格跨页位置
- 含大量行内公式的步骤页
- 行间公式密集页
- 图页及图前后页
- 小节标题与大表格、图片的交界页

## 4. 常见问题

### 4.1 行内公式显示为普通文本

说明公式没有进入 Word 数学对象，需要修复导出链或就地修复文档对象。

### 4.2 表格更新后标题错位

更新大表格后，必须检查：

- 表后小节标题是否仍在
- 编号是否正确
- 后续段落是否被误删

### 4.3 图片或附图说明错位

检查图片、图题、附图说明、正文图号引用是否仍然一致。

## 5. 交付门槛

只有同时满足以下条件，`docx` 才算可交付：

- 文本与 `md` 同步
- 行内公式和行间公式均正常
- 表格跨页可读
- 图片显示正常
- 标题层级与分页正常
