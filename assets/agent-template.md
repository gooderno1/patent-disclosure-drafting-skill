# 仓库工作规则

本目录后续按以下规则维护：

1. 专利交底书以 `md` 文档为唯一主编辑对象，直接在 Markdown 中写和改，不再通过 Python 脚本生成正文。
2. 配图不使用 `draw.io`、Mermaid、Python 生成脚本或其他程序化制图链路。
3. 需要插图时，统一使用 `gpt-image-2` 直接生成，再插入到对应的 `md` 文档中。
4. 交底书正文必须满足以下要求：
   - 方法步骤尽量用明确的数学语言描述；
   - 所有标量、向量、矩阵、集合、函数和阈值都要有定义；
   - 前后概念、符号、下标、缩写保持一致；
   - 附图名称、正文描述、变量命名保持一致。
5. 本目录不再保留现有的 Python 生成、渲染、导出链路；相关脚本和缓存应清理。
6. 如需后续导出为其他格式，优先基于现成的 `md` 文档处理，而不是重新引入脚本生成正文。
